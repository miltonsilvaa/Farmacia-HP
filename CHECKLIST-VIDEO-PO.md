# Funcionalidades — Grupo Farmácia HP

## Área do Cliente

### Conta
- [ ] Criar conta
- [ ] Entrar na conta
- [ ] Mostrar a senha ao digitar

### Tela inicial
- [ ] Pedido que precisa de resposta em destaque
- [ ] Acompanhamento do pedido em andamento
- [ ] Botão para enviar receita
- [ ] Remédios para renovar
- [ ] Atalhos para as outras áreas

### Enviar receita
- [ ] Escolher para quem é o remédio: para você, para um parente ou para um pet
- [ ] Tirar foto da receita ou enviar arquivo
- [ ] Enviar exames e outras receitas junto (até 5)
- [ ] Deixar recado para o farmacêutico
- [ ] Escolher produtos da farmácia
- [ ] Sugestões de produtos que combinam com o pedido
- [ ] Conferir tudo antes de enviar
- [ ] Número do pedido na confirmação

### Meus pedidos
- [ ] Pedidos separados em "Precisa da sua resposta", "Em andamento" e "Histórico"
- [ ] Ver o valor do orçamento e a mensagem da farmácia
- [ ] Aprovar o orçamento
- [ ] Recusar o orçamento
- [ ] Acompanhar o pedido em etapas: Solicitado, Em manipulação, Pronto e Entregue
- [ ] Ver como tomar o remédio, em letra grande
- [ ] Ver a receita e os arquivos enviados
- [ ] Falar com a farmácia pelo WhatsApp já com o número do pedido

### Renovação em 1 clique
- [ ] Renovar um pedido antigo com um clique
- [ ] Mesma receita, mesmos produtos, mesmo paciente e mesmo modo de uso
- [ ] Conferir paciente, remédio, como tomar e último valor antes de confirmar
- [ ] Aviso quando um produto não está mais à venda

### Grupo Família
- [ ] Cadastrar parentes
- [ ] Cadastrar pets
- [ ] Editar e remover parentes e pets
- [ ] Pedir remédio para um parente ou pet
- [ ] Convidar outra pessoa para cuidar da família junto (ex.: cônjuge)
- [ ] Aceitar ou recusar convite
- [ ] Quem foi convidado pode pedir e acompanhar os pedidos da família
- [ ] Os pedidos pessoais de cada um continuam privados
- [ ] Tirar o acesso de alguém ou sair de uma família

### Avisos por e-mail
- [ ] Receita recebida
- [ ] Orçamento pronto
- [ ] Receita recusada pela farmácia
- [ ] Pedido aprovado e em manipulação
- [ ] Pedido pronto para retirada
- [ ] Pedido entregue
- [ ] Lembrete de recompra quando o remédio está acabando

## Painel da Farmácia

### Fila do dia
- [ ] Resumo dos pedidos por situação
- [ ] Receitas esperando orçamento, da mais antiga para a mais nova
- [ ] Identificação de pedidos de renovação
- [ ] Ver a receita, os arquivos, o recado e os produtos pedidos
- [ ] Enviar orçamento com valor, mensagem e modo de uso
- [ ] Recusar receita com mensagem ao cliente

### Pedidos
- [ ] Lista de todos os pedidos
- [ ] Filtro por situação
- [ ] Busca por número do pedido, e-mail ou paciente
- [ ] Marcar pedido como pronto
- [ ] Marcar pedido como entregue
- [ ] Ver os detalhes do pedido
- [ ] Adicionar ou editar o modo de uso a qualquer momento

### Catálogo de produtos
- [ ] Cadastrar produtos
- [ ] Editar produtos
- [ ] Tirar produto de venda
- [ ] Controle de estoque
- [ ] Indicar produtos que combinam entre si

### Relatórios
- [ ] Total de pedidos
- [ ] Pedidos pendentes
- [ ] Faturamento
- [ ] Valor médio por pedido
- [ ] Pedidos por situação
- [ ] Pedidos e faturamento dos últimos 6 meses
- [ ] Baixar relatório em planilha do Excel

### Integração com o sistema da farmácia
- [ ] Pedido aprovado vai automaticamente para o sistema da farmácia
- [ ] Ver se o pedido chegou ao sistema
- [ ] Reenviar o pedido ao sistema
- [ ] Baixar os dados do pedido
- [ ] O modo de uso pode vir do sistema da farmácia

## Facilidade de uso
- [ ] Letra grande e fácil de ler, pensada para idosos
- [ ] Botões grandes
- [ ] Funciona no celular, no tablet e no computador
- [ ] Menu fixo embaixo da tela no celular
- [ ] Mensagem de confirmação ou de erro em toda ação
- [ ] Pergunta de confirmação antes de ações importantes
- [ ] Uso completo só pelo teclado

## Segurança
- [ ] Cada cliente só vê os próprios pedidos e os da família
- [ ] Área da farmácia acessível só pela equipe
- [ ] Receitas e dados de saúde protegidos
